# Report PDF fonts

The unmodified DejaVu Sans and DejaVu Sans Bold fonts are bundled for portable PDF generation. They include Latin and other Unicode glyphs; arbitrary scripts are not guaranteed. The Bitstream/DejaVu/Arev license is included in `LICENSE_DEJAVU`.
